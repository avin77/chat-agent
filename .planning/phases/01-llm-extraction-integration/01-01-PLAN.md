Make these changes to src/extractors/llmExtractor.ts:

1. FIX BUG on line 45: Change `phone.replace(/D/g, '')` to `phone.replace(/\D/g, '')`. This is critical — the current code only strips the letter 'D', not all non-digit characters. Phones like "+91 9876543210" silently fail validation without this fix.

2. ADD ExtractionMeta interface (export it — needed by llm-logger.ts and route.ts):
```typescript
export interface ExtractionMeta {
  sources: {
    phone?: 'llm' | 'regex';
    location?: 'llm' | 'regex';
    service_type?: 'llm' | 'regex';
    schedule?: 'llm' | 'regex';
    salary_range?: 'llm' | 'regex';
    family_size?: 'llm' | 'regex';
    has_experience?: 'llm' | 'regex';
  };
  latency_ms: number;
  llm_raw: ExtractedSlots | null;  // what LLM returned before any merge
  fallback_triggered: boolean;
}
```

3. ADD config arrays expressing field trust rules (use `as const`):
```typescript
const REGEX_WINS_FIELDS = ['phone'] as const;
const LLM_WINS_FIELDS = ['location', 'service_type', 'schedule', 'salary_range', 'family_size', 'has_experience'] as const;
```

4. ADD `mergeWithConflictResolution()` function (export it) — this is DIFFERENT from `mergeSlots()`. Do NOT modify mergeSlots():
   - For fields in REGEX_WINS_FIELDS (phone): if regexSlots.phone is non-null, use regex value. If regex is null, LLM value stands (may also be null).
   - For fields in LLM_WINS_FIELDS: if LLM value is non-null, keep it. If LLM is null AND regex is non-null, use regex value.
   - Include a docstring explaining "phone→regex wins, others→LLM wins on conflict, regex fills LLM nulls"

5. ADD `buildSourceMap()` function (export it) — builds the sources object for ExtractionMeta:
   - Iterates over all 7 fields (phone + LLM_WINS_FIELDS)
   - For each field where merged[field] is non-null: if merged[field] === llmSlots[field], source is 'llm'; else source is 'regex'
   - Skip name field (LLM never extracts name)

6. Keep existing `mergeSlots()` unchanged — it may be used by the existing catch block in `extractAllSlotsWithLLM()`.
