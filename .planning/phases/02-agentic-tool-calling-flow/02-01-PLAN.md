**handleMaidHireAgentic function:**

```typescript
export async function handleMaidHireAgentic(
  conversationId: string,
  latestMessage: string,
  coreMessages: any[],
  dbSession: any,
): Promise<{
  displayText: string;
  shouldEscalate: boolean;
  collectedData: Record<string, any>;
  tookMs: number;
  systemPrompt: string;
  rawResponse: string;
  extractionMeta: ExtractionMeta;
  promptTokens: number;
  completionTokens: number;
  totalTokens: number;
  estimatedCostUsd: number;
  newState: string;
}>
```

Function body:
1. Load collectedData from `dbSession?.collected_data || {}` (cast to CollectedData)
2. Parse consecutiveFailures from `collectedData.__consecutive_failures || '0'`
3. Check loop detection BEFORE calling LLM — if __loop_detected is 'true', return early with newState='LOOP_DETECTED', shouldEscalate:false, displayText: "Let me find the right way to help you..." (route.ts will fall back to deterministic)
4. Build systemPrompt with `buildAgenticSystemPrompt(collectedData)`
5. Call `generateText()` with `agenticTools`, `toolChoice: 'auto'`, system, messages: [{role:'user', content:latestMessage}] — do NOT wrap this in try/catch; let Gemini API errors propagate to route.ts
6. Capture usage: promptTokens, completionTokens, totalTokens
7. If toolCalls.length > 1: log warning, process only [0]
8. If toolCalls.length > 0: read toolResults[0].output; if success → save field to collectedData, reset failures, update __tool_calls count; if !success → increment consecutiveFailures
9. Update collectedData.__consecutive_failures = String(consecutiveFailures)
10. Check detectToolLoop → if true: set collectedData.__loop_detected = 'true', return with newState='LOOP_DETECTED'
11. Check shouldForceEscalateAgentic(consecutiveFailures) → force exit
12. Derive displayText: prefer result.text if non-empty after trim; if empty and tool called → use tool error or build "Got it! Next question" from remaining fields
13. Apply applyStrictGuardrails(displayText)
14. Check isComplete(collectedData) → shouldEscalate=true, newState='COMPLETE'
15. Check if escalate tool was called → shouldEscalate=true, newState='ESCALATED'
16. Determine newState as next missing required field (e.g., 'NEED_PHONE', 'NEED_LOCATION', etc.) or 'COMPLETE'
17. Save session to Supabase (update conversation_sessions: current_state=newState, collected_data=collectedData, attempts+=1 on failure, agentic_mode=true)
18. Return full result object
