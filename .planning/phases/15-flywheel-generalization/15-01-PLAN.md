# Plan 15-01: Cross-Intent Mining

**Requirement ID:** FLY-06, FLY-07
**One-liner:** Refactor mining scripts to support all canonical intents dynamically.

## Goal
Enable the data flywheel to harvest training data for `complaint`, `maid_registration`, and `general` intents, rather than just `maid_hire`.

## Tasks
1. **Generalize Missed Extractions**: Refactor `scripts/mine-missed-extractions.js` to iterate through `Object.keys(AGENTIC_PLAYBOOKS)`. 
    - Use `AGENTIC_STATE_MAP` for each intent to identify queryable states.
    - Update SQL query to support intent filtering.
2. **Generalize Golden Session Mining**: Refactor `scripts/mine-golden-from-prod.js` to reconstruct sessions based on the specific `fieldOrder` of the detected intent.
3. **Intent-Based Grouping**: Ensure mining logic groups results by intent before passing to the output formatter.

## Verification
- Run `npm run mine` and verify console logs show processing for multiple intents.
- Check that PII-redacted JSON results are correctly categorized.
