# Plan 15-04: AgentPlanner & Reflection

**Requirement ID:** AG-REFL
**One-liner:** Implement the autonomous planning service with "Judge" self-audit.

## Goal
Replace the deterministic field-picker with a reasoning engine that reflects on conversation history before deciding the next action.

## Tasks
1. **Create Planner Service**: Create `src/lib/agentic/planner.ts`.
    - Implement `AgentPlanner` class.
    - Define the "Judge" prompt persona that audits plans for duplicate asks, empathy needs, and history consistency.
2. **Confidence Logic**: Implement a confidence calculation based on slot ambiguity and history clarity.
3. **Structured Output**: Ensure the planner returns a JSON object: `{ reflection, nextAction, confidence, displayText }`.

## Verification
- Create unit tests in `src/lib/agentic/planner.test.ts`.
- Verify the planner successfully "self-corrects" when fed a mock history containing a duplicate phone number claim.
