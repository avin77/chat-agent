# Plan 15-03: Reasoning Persistence

**Requirement ID:** AG-L3
**One-liner:** Prepare database and logger for internal reflection storage.

## Goal
Update the `llm_logs` schema to support the persistent storage of the agent's internal thought process and confidence scores.

## Tasks
1. **Database Migration**: Create a Supabase migration script to add:
    - `thought_reflection` (TEXT, nullable).
    - `confidence_score` (INTEGER, nullable, range 0-100).
2. **LLM Logger Update**: Modify `src/lib/llm-logger.ts` (or the equivalent logging utility) to accept these new fields.
3. **Route Integration**: Update `src/app/api/chat/route.ts` to pass the `reflection` and `confidence` from the runtime result to the logger.

## Verification
- Run migration and verify `llm_logs` has the new columns.
- Mock a logger call and verify data is correctly persisted.
