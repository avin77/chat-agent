# Plan 15-05: 3-Strike Agentic Runtime

**Requirement ID:** AG-L3
**One-liner:** Integrate Planner into the runtime with retry and safety fallbacks.

## Goal
Upgrade the shared runtime to use the new Planner while enforcing the 3-strike self-correction policy.

## Tasks
1. **Runtime Refactor**: Update `src/lib/agentic/runtime.ts`.
    - Remove `nextMissingField()` as the primary decision maker.
    - Implement the retry loop: call `AgentPlanner`, check reflection for "correction" signals, retry up to 3 times.
2. **Safety Net Implementation**: If 3 strikes occur or confidence < 70%, trigger a hard fallback to the deterministic `nextMissingField()` checklist to ensure lead capture.
3. **Telemetry Integration**: Ensure the final chosen reflection and confidence score are returned in the `AgentDecision` object.

## Verification
- Rerun `test-agentic-runtime.ts` and verify it still passes with the new autonomous logic.
- Verify that a low-confidence scenario correctly triggers the deterministic safety net.
