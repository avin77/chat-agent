## Tech Debt Summary

### Phase 03 — Dashboard & Cost Tracking

1. **CONV-03/CONV-04: Confusion counter persistence bug** (Medium priority)
   - The `__confusion` counter is incremented in-memory on `session.collectedData` but the result passed to `saveStateMachineSession` comes from `maidHiringFlow.processMessage()` which returns its own `collectedData`. The incremented value is never written to DB.
   - **Fix:** In `handleMaidHireStateMachine`, after processMessage() returns, spread `__confusion` into `result.collectedData` before calling `saveStateMachineSession`. One line change.

2. **12 IDs orphaned from REQUIREMENTS.md** (Low priority)
   - SHADOW-01–04, CONV-01–04, ALERT-01–04 referenced in ROADMAP and plans but not formally defined in REQUIREMENTS.md.
   - **Fix:** Add formal definitions to REQUIREMENTS.md for all 12 IDs.

3. **ALERT-04 cost sub-check always inactive** (Low priority — intentional)
   - `DAILY_TOKEN_BUDGET_USD` env var must be set for cost alert to fire. As documented.
